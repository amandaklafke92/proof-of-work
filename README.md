# Proof of Work

A small public portfolio index for selected projects by Amanda Esnaola.

This repo is meant for CV and reference purposes. It does not try to expose every
source repository. Instead, it collects polished write-ups, demos, and selected
assets that show the thinking behind the work: problem framing, product choices,
AI collaboration patterns, and practical execution.

## Published Projects

- **Personal OS** - a long-form case study about building a file-based operating
  system for AI-assisted work, context management, and project continuity.
- **Workout Tracker** - a short case study and static demo of a private
  Google Sheets and Apps Script workout system with a mobile-first interface.

Flavour Lab will be added later when its public case study or curated demo is
ready.

## Structure

- `index.html` - landing page for the portfolio.
- `personal-os/` - Personal OS case study and assets.
- `workout-tracker/` - Workout Tracker case study, assets, and demo.
- `NOTES.md` - working notes for future additions.

## Public Data Boundary

Workout Tracker demo data may include workout names, weights, volumes, and
related training metrics. Amanda has marked this acceptable for public
portfolio/demo use because realistic data makes the app easier to test and
understand.

Private source repositories, credentials, live Google Sheet links, raw project
logs, unrelated personal records, meeting notes, and third-party private
material should stay out of this repo unless Amanda explicitly marks the
specific material public-safe.
