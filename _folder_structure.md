# Proof of Work - Folder Structure
*Last updated: 2026-09-09*

## Structure

- `index.html` - public landing page for the proof-of-work portfolio.
- `personal-os/` - the flagship long-form Personal OS case study.
- `personal-os/assets/` - Personal OS case-study images.
- `workout-tracker/` - Workout Tracker case-study page.
- `workout-tracker/demo/` - standalone Workout Tracker demo using copied workout data and browser-local storage.
- `workout-tracker/assets/` - Workout Tracker imagery.
- `NOTES.md` - maintenance notes for adding future projects.

## Naming Convention

Use lowercase kebab-case for project folders and public asset names. Each project gets its own folder with an `index.html` entry point.

## Privacy

Workout Tracker demo data may include workout names, weights, volumes, and related training metrics; Amanda has marked those acceptable for public portfolio/demo use because they make testing realistic. Keep private source, credentials, live Sheet links, raw logs, unrelated personal records, meeting notes, and third-party private material out of this repository unless Amanda explicitly marks the specific material public-safe.
